WebMCP: Chuẩn Web Mới Biến Website Thành Công Cụ AI

01/10/2026 · Web MCP & AI Agents

WebMCP — chuẩn web W3C do Google và Microsoft cùng đề xuất — đang thay đổi cách AI agent tương tác với website. Thay vì "cào dữ liệu" hay giả lập thao tác chuột, website chủ động khai báo các công cụ và hành động mà AI có thể gọi trực tiếp. Đây là bước ngoặt lớn cho cả lập trình viên web lẫn đội ngũ phát triển AI.

📌 Điểm chính

1

WebMCP là gì và khác gì MCP của Anthropic?

MCP (Model Context Protocol) của Anthropic là giao thức phía server — kết nối AI với các nguồn dữ liệu backend. WebMCP là API phía client chạy trên trình duyệt, cho phép website khai báo JavaScript functions và HTML forms trực tiếp cho AI agent. W3C Draft chính thức ra mắt vào ngày 10/02/2026; Chrome 146 Canary đã triển khai thử nghiệm sau đó.

2

Chrome 149 mở Origin Trial — bạn có thể thử ngay

Chrome 149 triển khai Origin Trial cho WebMCP, cho phép developer đăng ký thử nghiệm trên trang web thực. Thay vì agent phải đoán giao diện hay click mù, website cung cấp schema rõ ràng: "đây là các hành động tôi hỗ trợ, đây là cách gọi chúng". Ít lỗi hơn, ít scraping hơn, trải nghiệm người dùng tốt hơn.

3

MCP Spec 2026-07-28: Đại tu giao thức lõi

Phiên bản MCP mới nhất (07/2026) mang thay đổi lớn nhất kể từ khi ra mắt: giao thức chuyển sang stateless (không còn session), hỗ trợ Multi Round-Trip Requests, bảo mật authorization cứng hơn, và framework extension chính thức. AWS đóng góp extension "Tasks" cho long-running agents. Cloudflare Agents SDK hỗ trợ spec từ ngày đầu ra mắt.

4

Browser automation MCP đang bùng nổ

Browser Use đạt 78K GitHub stars chỉ trong chưa đầy một năm. Các MCP server phổ biến nhất cho browser automation 2026 gồm: Playwright MCP, Browserbase, mcp-chrome, Browser Use, và Chrome DevTools MCP. Cloudflare cũng ra mắt "Browser Run" — chạy browser session trực tiếp trong Workers, cho phép các AI agent như Claude Desktop hay Cursor dùng browser từ xa.

5

Thách thức bảo mật với MCP mới

SecurityWeek cảnh báo: MCP spec Enterprise-Ready mới mang đến những thách thức bảo mật mới — đặc biệt khi AI agent có quyền gọi tool trực tiếp vào hệ thống. Cần kiểm soát chặt chẽ permission scope, audit log, và rate limiting cho các MCP server production.

💡 Tại sao quan trọng với bạn?

Nếu bạn là frontend dev: WebMCP sắp trở thành yêu cầu bắt buộc — website không hỗ trợ WebMCP sẽ bị AI agent xử lý kém hơn. Nếu bạn làm backend/AI: MCP stateless spec mới thay đổi cách thiết kế server; cần review lại kiến trúc nếu đang dùng session-based MCP. Với product team: đây là cơ hội tích hợp AI agent vào sản phẩm theo hướng "agent-ready" thay vì patch sau.
